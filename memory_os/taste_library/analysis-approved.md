## What "Excellent" Means in This Domain

Based on your learning preferences from CLAUDE.md:

- **Lead with what, then how, then why** — never bury the answer in context
- **One key insight per section** — if a paragraph makes 3 points, split it
- **Concrete over abstract** — always show an example after a principle
- **Teach mode on** — explain as if I'm building mental models, not just reading facts
- **No over-summary** — if you explained something, don't re-explain it at the end
- **Tables for comparisons** — when comparing ≥3 options, use a table, not paragraphs
- **Action at the end** — every analysis should end with at least one clear "so what" or next step
- **Length discipline**: if it can be said in 3 sentences, don't use 3 paragraphs
