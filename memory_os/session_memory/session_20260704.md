### 2. Real-World Verification vs. Test-Only Acceptance

**User Directive:** "Tests passing is not sufficient; verify the UI works live."

This forced **three critical bug fixes** found only through actual usage, not test suites:

#### Bug #1: Unhandled OpenRouter 429 Rate-Limit
- **Symptom:** Bare 500 error with no readable message when OpenRouter returned 429 (rate-limit).
- **Root:** FastAPI exception handler not catching provider API errors cleanly.
- **Fix:** Added explicit exception handler returning clean 502 with human-readable rate-limit message.

#### Bug #2: Critical — FallbackProvider Timeout Logic Broken
- **Symptom:** Single `generate()` click could hang 8+ minutes with zero user feedback.
- **Root:** `requests` library timeout parameter only caps inactivity *between socket reads*, not total call duration. A single LLM generate() call could iterate for 8+ minutes and never trip the timeout.
- **Fix:** Implemented genuine wall-clock deadline using `concurrent.futures.ThreadPoolExecutor` + `Future.result(timeout=)`. Verified: the exact call that hung 8+ minutes now completes in 1.1 seconds.
- **Learning:** First fix attempt had a subtle bug of its own—wrapping ThreadPoolExecutor in a `with` block causes exit to block until the thread finishes, silently reintroducing the hang. Caught by a test asserting `elapsed_time < 2.0s`.

#### Bug #3: nac Console Script Not on PATH
- **Symptom:** `nac` command not found after install.
- **Root:** Python312\Scripts not in system PATH on this machine.
- **Workaround:** `py -3 -m dashboard` works; updated docs.

#### Bug #4: Earlier Commit Message Lied
- **Symptom:** Claimed a fix was committed, but `git add -A -- dashboard nac tests` had excluded `engine/` directory, so the actual fix was never staged/committed.
- **Root:** Trusted commit message over actual git state.
- **Fix:** Ran explicit `git status` before declaring done; re-staged `engine/` changes in a follow-up commit.
- **Learning:** Always verify against filesystem/git state; don't trust self-report or commit message alone.
