# Cognitive Runtime Platform (CRP)
Cognitive Runtime Platform is a measurement-first adaptive runtime staged in `crp/`; Phase 0 is functionally complete (telemetry, Dense/Int8 harness, Experience DB, replay, exit report PASS), governance is frozen, and Gates 1-2 are implemented and merged to `master` (PR #26, PR #27), with the Gate 2 Compiler Conformance Report open as [PR #28](https://github.com/navakanth1984/AgentOSClaude/pull/28) (`MERGEABLE CLEAN`). **CRP is the execution platform inside Project TITAN's long-term vision** (quantum-inspired adaptive runtime, 15+ representations) — not a sibling project; TITAN capabilities enter only via RFC + empirical evidence, never directly. The `docs/vision/TITAN.md` file was believed missing after a `git log --all` ref search turned up nothing on 2026-07-03, but was recovered same-day: it existed as orphaned commit `784a22fc` (2026-07-02, on a superseded branch never merged to master, so absent from every ref). Recovered via `git show 784a22fc:docs/vision/TITAN.md`, and after a later rebase to resolve PR #28's conflicts with the merged `master`, it now lands as part of commit `38238434` on `docs/crp-gate2-freeze` (PR #28), with the layer-model correction folded in directly.

## Runtime Shape
- Replayable workload definitions live in [workloads.py](../crp/runtime/crp_runtime/workloads.py), with `WorkloadSpec`, `SyntheticTensorWorkload`, and `EmbeddingSearchWorkload`.
- Representation interfaces and Dense fallback live in [representations.py](../crp/runtime/crp_runtime/representations.py); the Int8 implementation lives in [plugins_int8.py](../crp/runtime/crp_runtime/plugins_int8.py).
- Deterministic hard-constraint selection lives in [policy.py](../crp/runtime/crp_runtime/policy.py), and the telemetry-integrated run path lives in [harness.py](../crp/runtime/crp_runtime/harness.py).
- The frozen Python-facing Tier-0 telemetry API is [crp_telemetry.pyi](../crp/runtime/crp_telemetry.pyi); changes require a defect correction or RFC per the [Phase 0 design spec](../docs/superpowers/specs/2026-07-02-crp-phase0-design.md).
